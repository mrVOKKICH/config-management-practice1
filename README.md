# Эмулятор оболочки UNIX

Практическая работа № 1 по дисциплине «Конфигурационное управление»,
группа ИКБО-61-25, вариант 11.

## 1. Общее описание

Консольный эмулятор языка оболочки UNIX-подобной ОС с виртуальной файловой
системой (VFS). Написан на Python 3.8+ и не требует сторонних библиотек.

Статус: **этап 2 — конфигурация**.

## 2. Функции и настройки

Приглашение к вводу содержит имя VFS: `vfs$ `. Если указан `--vfs-path`,
именем VFS становится имя этой директории.

Параметры командной строки (при запуске выводятся в отладочном виде):

| Параметр       | Описание                                           |
|----------------|----------------------------------------------------|
| `--vfs-path`   | путь к физическому расположению VFS                |
| `--script`     | путь к стартовому скрипту                          |

С `--script` эмулятор выполняет скрипт (показывая ввод и вывод, как в
диалоге) и завершается; без него запускается интерактивный режим.
В скриптах `#` начинает комментарий, ошибка команды не прерывает скрипт.

Ввод делится на команду и аргументы по пробелам.

| Команда | Описание                                         |
|---------|--------------------------------------------------|
| `ls`    | заглушка, выводит своё имя и аргументы           |
| `cd`    | заглушка, выводит своё имя и аргументы           |
| `exit`  | завершает работу эмулятора                       |

Ошибки: неизвестная команда (`foo: команда не найдена`) и лишние аргументы
у `exit`.

## 3. Сборка и тесты

Сборка не требуется. Запуск и тесты:

```sh
./run.sh                 # Linux/macOS (Windows: run.bat)
make test                # тесты (unittest)
sh scripts/stage2_params.sh   # проверка параметров (Windows: .bat)
```

Без `make`: `PYTHONPATH=src python3 -m unittest discover -s tests -v`
(Windows: `set PYTHONPATH=src` и `python -m unittest discover -s tests -v`).

## 4. Примеры использования

```text
$ ./run.sh
vfs$ ls -l /home
ls -l /home
vfs$ cd /tmp
cd /tmp
vfs$ foo
foo: команда не найдена
vfs$ exit now
exit: лишние аргументы
vfs$ exit
```
